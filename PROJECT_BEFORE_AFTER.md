# Ладно: было - стало

Сравнение сделано между актуальной оригинальной веткой `upstream/main` проекта `moodee` и текущей веткой `codex-improvements`.

Итог: ветка `codex-improvements` лежит поверх `upstream/main` и добавляет продуктовые функции дневника, аналитику, CSV-экспорт, ограничения редактирования, тесты и документацию. Изменения `main` с переименованием в `Ладно` сохранены.

## Общее состояние

Было в `upstream/main`:

- базовый Django MVP дневника настроения;
- регистрация, вход, профиль и выход;
- запись дня с датой, настроением, самочувствием, активностью и заметкой;
- история записей с фильтрами;
- простая статистика и график;
- rule-based AI-отчет прямо во view;
- практики и demo email-напоминания;
- экспорт данных был только заглушкой;
- тестовые файлы в `mood` и `ai_reports` были пустыми;
- проект уже был переименован в `Ладно` в пользовательских текстах.

Стало в `codex-improvements`:

- дневник хранит больше контекста дня: стресс, тревожность, сон, факторы, благодарность;
- добавлены правила качества данных: одна запись на пользователя в день, заметка до 400 символов, редактирование только 24 часа;
- dashboard стал экраном ежедневного check-in;
- история и аналитика показывают новые поля;
- CSV-экспорт стал реальной функцией;
- AI-отчет вынесен в сервис и стал учитывать новые метрики;
- добавлены базовые тесты модели, формы, edit-window и сервиса отчета;
- обновлены `.env.example`, `docker-compose.yml`, `.gitignore`, README и техническая документация.

## Что реально добавляет ветка

1. Расширенная модель дневника состояния.
2. Правила данных: уникальная дата, лимит заметки, edit-window 24 часа.
3. CSV-экспорт истории с учетом фильтров.
4. Более полезный dashboard.
5. Расширенная аналитика и графики.
6. Rule-based сервис персональных инсайтов вместо логики внутри view.
7. Улучшенные шаблоны и CSS для новых сценариев.
8. Документация и инструкции запуска.
9. Базовые тесты критичных правил.
10. Более пригодная локальная конфигурация env/docker.

## Что не добавлено

- Нет новых Python-зависимостей.
- Нет новых frontend-зависимостей.
- Нет внешнего AI API или LLM.
- Нет REST API.
- Нет Celery/RQ/scheduler для production-напоминаний.
- Нет мобильного приложения.
